# ADR-002 — Design system BIRNIN GOBE

**Décision :** reconstruire les maquettes avec des composants React réutilisables et des tokens centralisés, plutôt que rendre les captures comme images.

Palette de base : vert résilience, vert profond, or opportunité, crème et encre. Les rayons, ombres, espacements, états de focus et composants de formulaire sont centralisés dans `resources/css/app.css`.
