# Localisation

- `fr.ts` contient les textes statiques de l'interface.
- Le haoussa et le zarma ne sont **pas inventés** dans ce prototype : les traductions sensibles doivent être validées institutionnellement.
- Le runtime doit utiliser le français comme fallback lorsque la traduction d'une locale validée manque.
- Les contenus dynamiques (FAQ, thématiques, critères, textes d'aide, notifications) doivent provenir du CMS / de la base avec tables de traductions.
